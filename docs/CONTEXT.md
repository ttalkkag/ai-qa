# 공통 용어

## 관리자 (Administrator)

계정을 관리하고 프로젝트의 작업 조건을 정하며 결과의 외부 발행을 승인할 수 있는 사용자다. 서버를 실행한 사람이라도 앱에서는 관리자 계정으로 로그인해야 한다.

_Avoid_: 호스트 권한, 같은 PC 사용자, 관리자 기기.

## 매니저 (Manager)

허용된 프로젝트에서 요구사항을 설명하고 자신의 작업을 진행·확인하는 사용자다. 원격 저장소에 결과를 발행할 권한은 없다.

_Avoid_: 외부인, 익명 요청자, 개발자 권한.

## 관리자 메뉴 (Admin)

관리자가 요청 결과의 발행을 검토하고 사용자 계정과 서비스 운영을 관리하는 진입점이다. 메뉴를 여는 것과 개별 작업을 승인하는 것은 별개다.

_Avoid_: 내 계정, 모든 요청의 자동 승인, 관리자 역할 자체.

## 내 계정 (Account)

로그인한 사용자가 자신의 아이디를 확인하고 닉네임·비밀번호를 변경하며 로그아웃하는 개인 영역이다. 이메일은 표시하거나 입력받지 않는다. 아이디는 로그인용 고유 username이고 닉네임은 별도의 display_name이다. 다른 사용자의 계정이나 프로젝트 권한을 관리하는 영역은 아니다.

_Avoid_: 계정 관리 전체, 관리자 설정.

## 서비스 사용 가이드 (Docs)

매니저가 프로젝트 선택부터 요청 작성·실행 상태·결과 확인까지 따라갈 수 있는 사용 안내다. 개발용 기획서나 프로젝트의 원본 문서를 공개하는 기능은 아니다.

_Avoid_: 개발 기획서, 저장소 문서 탐색기, 운영자 설치 매뉴얼.

## 프로젝트 (Project)

요청이 적용되는 코드와 작업 조건을 묶는 업무 단위다. 프로젝트에 소속되어 있다는 사실과 개별 요청의 소유자는 서로 다른 접근 조건이다.

_Avoid_: 채팅방, 파일 경로 자체.

## 대화 (Conversation)

하나의 문제를 설명하고 구체화하며 관련 작업 결과를 이해하는 대화 기록이다. 대화를 이어간 사실만으로 코드 수정이나 발행에 동의한 것은 아니다.

_Avoid_: 모델 세션, 실행, 승인.

## 작업 요청 (Work Request)

해결하려는 문제와 기대하는 변경을 표현한 업무 항목이다. 요청의 명세 준비 상태는 실제 코드 작업의 진행 상태와 구별한다.

_Avoid_: 프롬프트, 실행 결과.

## 확정 명세 (Request Revision)

사용자가 검토해 확정한 변경 범위·완료 기준·코드 기준의 수정 불가능한 한 판본이며, 코드 수정 시작이나 발행 승인은 별도 결정이다. 본문이나 코드 기준을 바꾸면 기존 판본을 고치지 않고 새 판본을 확인한다.

_Avoid_: 최신 대화 전체, 실행 중 변경사항.

## 실행 (Run)

확정 명세를 바탕으로 코드를 수정하고 검증하는 한 번의 시도다. 재시도는 이전 기록을 덮어쓰지 않는 별도 실행이다.

_Avoid_: 요청, AI 응답, 세션.

## 작업 사본 (Workspace)

원본 코드를 보존하면서 한 실행에서만 수정할 수 있게 준비한 코드 사본이다.

_Avoid_: 원본 저장소, 공유 작업 폴더.

## 검증 (Verification)

변경 전후에 실제로 실행한 검사와 그 증거를 비교하여 완료 기준 충족 여부를 확인하는 과정이다. AI의 설명이나 검사 생략은 통과 증거가 아니다.

_Avoid_: AI가 괜찮다고 함, 무조건 테스트 성공.

## 결과 묶음 (Result Bundle)

한 실행에서 얻은 변경 내용·검증 증거·요약을 함께 고정한 결과다. 승인 후 내용을 바꿀 수 없으며 다른 결과를 승인하려면 새 승인이 필요하다.

_Avoid_: 현재 작업 폴더, 마지막 답변.

## 결과 확인과 로컬 승인 (Result Review)

요청자가 수정 결과를 확인해 완료 또는 재수정을 선택하고, 완료 확인 이후 관리자가 같은 결과 해시를 승인하거나 보완 요청하는 기록이다. 로컬 승인은 원격 작업을 실행하지 않는다.

_Avoid_: AI 응답의 성공 문구, 코드 실행 성공, push 승인.

## 원격 발행 승인 (Approval)

관리자가 특정 결과를 특정 원격 대상에 발행하도록 허락한 기록이다. 코드 수정 시작 확인과는 별개의 결정이다.

_Avoid_: 채팅의 긍정 답변, AI 검토, 접속 기기 인증.

## 발행 (Publication)

승인된 결과를 새 원격 브랜치에 올리고 선택한 경우 검토용 PR을 만드는 작업이다. 발행은 병합이나 배포를 포함하지 않는다.

_Avoid_: 로컬 저장, 자동 배포, 실행 성공.

## 모델 프로필 (Model Profile)

대화나 코드 수정 등 목적에 맞춰 관리자가 선택한 모델과 사고 강도의 조합이다. 사용자가 이를 직접 선택하지 않아도 각 AI 호출에 실제 선택이 기록된다.

_Avoid_: 자동 무제한 고성능, 조용한 대체 모델.
