# 멀티 프로젝트 제안 용어

MP-001 검토에만 사용하는 용어 초안이며 제품의 확정 용어가 아니다
현재 Project·RequestRevision·Run·Workspace의 정의는 [공통 용어](../../CONTEXT.md)를 따른다

## Language

**작업 그룹 (ProjectGroup)**:
하나의 사용자 요청을 함께 처리할 수 있도록 기존 프로젝트들을 연결한 업무 단위다. 저장소 자체나 실행 중인 작업 사본은 아니다
_Avoid_: 메인 저장소, Workspace, 상위 Git 저장소

**그룹 구성원 (ProjectGroupMember)**:
작업 그룹에 연결된 프로젝트와 그룹 안에서의 별칭·메인 여부·참여 한도를 나타낸다. 그룹 연결만으로 사용자 접근 권한을 부여하지 않는다
_Avoid_: 사용자 멤버, 자동 권한 상속

**메인 프로젝트 (Main Project)**:
그룹에서 주요 업무 대상으로 표시하는 프로젝트이며 복수 지정할 수 있다. 실행 순서나 파일 수정 권한을 뜻하지 않는다
_Avoid_: 유일한 루트, 먼저 실행할 프로젝트, 무제한 수정 대상

**분석 시작점 (Analysis Entry)**:
요청을 이해할 때 우선 살펴볼 프로젝트에 대한 선택적 힌트다. 시작점이 없어도 관련 프로젝트의 허용 문맥을 함께 분석할 수 있다
_Avoid_: 실행 cwd, 메인 프로젝트, 고정 실행 순서

**요청 대상 (Request Target)**:
확정 명세에 포함된 프로젝트별 읽기·수정 범위, 기준 코드와 정책 버전의 묶음이다. 그룹 구성원 중 실제 요청에 필요한 대상만 포함한다
_Avoid_: 그룹의 모든 프로젝트, AI가 자유롭게 추가하는 경로

**통합 결과 (Combined Result)**:
요청 대상별 결과와 함께 수행한 연동 검증을 하나의 명세에 묶은 불변 결과다. 저장소별 여러 커밋을 하나의 Git 커밋으로 합친다는 의미가 아니다
_Avoid_: 대표 저장소 결과, 일부 성공을 전체 성공으로 표시
