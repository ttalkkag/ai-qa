# AI Debug 문서

이 저장소는 AI Debug 제품 아이디어를 정리하는 문서 작업 공간입니다.

## 문서

- [기획서](./docs/plan/README.md)
- [구현 계획](./docs/report.md)
- [리서치](./docs/research/README.md)

## 기준

- 구현 기준은 리서치와 기획서입니다.
- 문서는 내부 프로젝트를 주요 대상으로 가정합니다.
- 모노레포는 DDD 도메인 경계, 단일 서비스 저장소는 MSA 서비스 경계를 기준으로 봅니다.
- 각 도메인 또는 서비스는 동일한 `.ai-context` 구조를 가진다고 전제합니다.
